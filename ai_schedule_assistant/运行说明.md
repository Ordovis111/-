# 可运行说明

## 一、环境要求
- 操作系统：Windows / macOS / Linux 均可
- Python：3.10 及以上
- 无需 GPU，普通笔记本即可运行

## 二、安装依赖
打开终端（命令行），进入本项目文件夹，执行：

```bash
pip install -r requirements.txt
```

依赖清单见 requirements.txt，主要包括：
- streamlit：Web 界面
- openai：调用大模型（兼容接口）
- python-dotenv：读取配置
- pandas：表格处理

## 三、配置大模型（可选）
不配置也能直接运行，会自动进入本地演示模式。

1. 复制 `.env.example` 为 `.env`；
2. 填入百度千帆（文心一言）的密钥：
   ```
   LLM_API_KEY=你的APIKey
   LLM_MODEL=ernie-5.1
   ```
3. 密钥获取地址：https://console.bce.baidu.com/qianfan/

## 四、启动运行
在项目文件夹下执行：

```bash
streamlit run app.py
```

启动后浏览器会自动打开（默认地址 http://localhost:8501 ）。
若提示 Streamlit 邮箱收集，直接留空按回车跳过即可。

## 五、使用步骤
1. 左侧边栏选择计划开始/结束日期，填写每日可用时段（如 `09:00-12:00, 14:00-22:00`）；
2. 在"我需要做的事"框里用自然语言输入任务；
3. 点击「AI 分析并填入表」，日程会自动排进周表；
4. 可继续用自然语言下达"删除/修改"指令，或手动添加事项；
5. 满意后点击「导出为日历文件 (.ics)」下载。

## 六、目录结构
```
ai_schedule_assistant/
├── app.py            # 主程序，Streamlit 界面入口
├── llm_client.py     # 大模型调用与任务解析
├── scheduler.py      # 本地排程算法与 .ics 导出
├── requirements.txt  # 依赖清单
├── .env.example      # 配置模板
└── 运行说明.md
```

## 七、常见问题
- **打开是英文/报错找不到模块**：确认已在项目文件夹内执行 `pip install -r requirements.txt`，且用的是同一个 Python 环境。
- **提示"演示模式"**：说明 `.env` 里没填有效密钥，程序自动用本地规则解析，功能仍可演示。
- **日期排错**：确保系统时间正确；程序会自动把"今天是周几"告诉大模型。
- **端口被占用**：加参数换端口，如 `streamlit run app.py --server.port 8600`。
